Blue Prince 实验室 — 元素混合与 7 种稳定配方

2026 年 5 月 25 日更新 · 9 分钟阅读 · 含全部 7 种稳定配方

实验室是 Mt. Holly 庄园中少数能永久改变存档的房间之一。把三个药瓶放上烧瓶，看反应——稳定就获得永久加成（跨所有未来 run 生效），不稳定则烧瓶炸裂，背包中随机一件非关键物品消失。共有 7 种安全配方、两种必死混合，以及一个用储藏室连续两天访问实验室的小技巧。

速查：7 种稳定组合为 铁+盐+煤（+1 Coin/天）、汞+灰+铁（开锁器）、盐+硫+灰（+1 Key 抽取）、蜜+汞+煤（储藏室 Step 翻倍）、硫磺石+铁+硫（火焰杖）、蜜+盐+硫磺石（金库提示）、灰+煤+汞（+5 Step 临时）。其余皆有风险。

烧瓶规则

实验室烧瓶有三个槽位、一个火焰强度旋钮、一个点火杆。界面比看起来简单：

  1. 只允许三个药瓶。放第四个会清空槽位。没有两瓶配方。
  2. 火焰大小是装饰。大火小火反应一致，只是烟的颜色不同。
  3. 每天只能混一次。点火后实验室门锁定至当日结束。
  4. 失败混合不消耗全局药瓶。背包中的瓶子保留。爆炸消耗的是一件其他物品。

7 种稳定配方

1. 铁 + 盐 + 煤 — 铸币

多数玩家解锁的第一种。每日 Coin 收入永久 +1。试剂便宜，三种都在入口架上能拿到。任何新存档建议首选。

2. 汞 + 灰 + 铁 — 开锁器

每天开局背包多一把开锁器。可开一扇锁门不消耗 Key。重复混合会覆盖，无叠加效果。

3. 盐 + 硫 + 灰 — Key 抽取

每抽取一间新房间，+15% 概率刷出 Key。长线最强的配方——Key 经济是 Day 5+ 的瓶颈。

4. 蜜 + 汞 + 煤 — 储藏室倍化

储藏室再入时给予双倍 Step。只在你抽到储藏室时生效——Day 2 后大多数局面会自然抽到。

5. 硫磺石 + 铁 + 硫 — 火焰杖

永久火焰杖放入背包。可烧穿木门，代价 5 Step。对遗忘之翼路线有用，但消耗 Step 多，大部分 run 难以回本。

6. 蜜 + 盐 + 硫磺石 — 金库提示

金库密码字母（D-O-O-R = 4558）在未来每次首次进入金库时预先显示。如果你已经记住密码，可以跳过。

7. 灰 + 煤 + 汞 — Step 加成（仅本局）

唯一的非永久稳定配方。当前一天 Step 上限 +5。除非中场缺 Step 否则跳过。

两个会毁掉 run 的混合

  • 硫磺石 + 汞 + 任意第三种。所有含硫磺石与汞的组合都会爆炸。汞与硫化物太不稳。损失一件随机非关键物品——多为钱袋。
  • 蜜 + 铁 + 煤。看起来安全（三种常见元素），但产生「焦油泥」，使当日 Coin/Key/Step 收入全部归零。
记住危险对：三个药瓶中如果同时含硫磺石和汞，必定失败。没有任何安全的硫磺石+汞组合。

储藏室连续访问技巧

在实验室旁边抽一个储藏室，可以以接近零 Step 成本在连续两天内访问实验室。Day N 混合 Formula A，实验室锁定。睡觉。Day N+1 实验室重新抽取（稀有度刷新），走三格穿过储藏室到同一实验室格子，混合 Formula B。两天两个永久加成。

推荐路径：用此方法在 Day 3 前刷出配方 1、2、3（铸币、开锁器、Key 抽取）。

配方对存档的写入

永久配方（1、2、3、4、5、6）会写入存档的「实验室解锁」数组。它们会保留：

  • 跨死亡
  • 跨 Permadeath 重启（是的，实验室解锁不会被 Permadeath 抹除）
  • 跨 New Game+ —— 但在该 NG+ 中需要重新混合才能再次启用

实验室常见问题

实验室需要特定房间相邻吗？ 不需要。实验室是「稀有」级房间，约 7% 抽取率。先抽到图书馆或书房会略微提升下一天的实验室抽取率（剧情主题聚类）。
背包没有药瓶能混合吗？ 可以。实验室西墙的架子上每种元素都有一份，不需要自带。
中途离开会怎样？ 没拉点火杆就离开等于取消。但当日的混合机会仍然算作用掉，不能重试。
有第 8 个隐藏配方吗？ 数据挖掘表明没有。社区已测试全部 28 种三元素组合：7 种稳定、2 种危险、19 种「无反应」。
