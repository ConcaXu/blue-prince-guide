前厅 — 四扇门、石柱与基础钥匙

2026 年 5 月 25 日更新 · 8 分钟阅读 · Rank 9 中心枢纽

前厅(Antechamber)是庄园本体与 46 号房之间的关口。固定在 Rank 9 中心 — 5×9 庄园网格顶部 — 不需抽取。四扇门(北/南/东/西)默认全锁,每扇都由一间另外的房间里的控杆开。本页覆盖四扇门、三间控杆室、升起石柱机制,以及前厅在 Room 46 链中的位置。

速查：前厅 = Rank 9 中心,固定。南/东/西门由 Great Hall、Secret Garden、Greenhouse(坏)的控杆开。北门由地下室 Inner Sanctum 控杆开。首次进入时,石柱升起,内含基础钥匙、津贴令牌,以及注解:"To continue up, one must go down."

网格位置

前厅是庄园仅有的两个固定房之一。另一个是玄关(Rank 1 中心)。它们界定每局南北两端：

  • 玄关 — Rank 1,第 3 列(中)。每天起点。
  • 前厅 — Rank 9,第 3 列(中)。需要抵达的目标。
  • 46 号房 — Rank 10。前厅北门后唯一的房。

中间是 5×9 = 45 间的抽取网格。前厅不抽取 — 永远在顶部等你。

四扇门

门控杆位置状态
南(S)Great Hall / Secret Garden / Greenhouse 之一可用(Greenhouse 除外 — 坏)
东(E)Great Hall / Secret Garden / Greenhouse 之一可用(Greenhouse 除外 — 坏)
西(W)Great Hall / Secret Garden / Greenhouse 之一可用(Greenhouse 除外 — 坏)
北(N)Inner Sanctum(地下室)开 46 号房门的控杆

哪个控杆开哪扇门(S/E/W)的对应在每存档固定 — 一旦发现 Great Hall 开南门,这映射对该存档余下时间都成立。

三间控杆室

Great Hall

最容易抵达的控杆。普通房,抽取概率高。控杆在大厅深处,中央楼梯后。拉一次永久解开它对应的前厅门。

Secret Garden

需要 Secret Garden Key,随机生成。最佳来源:台球室飞镖盘奖(可能掉特殊钥匙之一)、Music Room、Locksmith。控杆在花园深处,喷泉附近。

Greenhouse(坏)

Greenhouse 里有控杆,但不工作。这是设计的,房内注解会提到。别浪费 run 拉它 — 找其他控杆室。

首次进入时升起的石柱

首次走入前厅,石柱从地板升起。顶部三件物品：

  1. 基础钥匙(Basement Key)。开两个地下室入口:Foundation 电梯(若抽到)和抽干喷泉后的井底门。开过的门跨 run 永久保留。
  2. 津贴令牌。永久提升每日 Coin 上限。存档级升级。
  3. 注解："To continue up, one must go down." — 提示下一步是地下室。
基础钥匙每晚重置。用之前不要睡。睡了,钥匙回到石柱 — 下一 run 要再次解控杆室进前厅再领。它打开过的地下室门跨 run 永久保留。

北门控杆在 Inner Sanctum

前厅四扇门中三扇只给你进的方式。只有北门通 46 号房 — 它的控杆不在庄园里,而在地下室深处的 Inner Sanctum。

完整序列：

  1. 拉 S/E/W 控杆(Great Hall、Secret Garden 或 Greenhouse 若没坏)。
  2. 进前厅,从石柱拿基础钥匙。
  3. 经 Foundation 电梯 或 已抽干的喷泉井下地下室(用基础钥匙开门)。
  4. 穿过地下室到齿轮谜题室。
  5. 解齿轮谜题抵达 Inner Sanctum。
  6. 拉北门控杆。
  7. 走回前厅。北门已开,进去就是 46 号房。

地下室与齿轮谜题详细攻略:见46 号房间走法。

通关 46 号房后,前厅还有什么

首次抵达 46 号房会触发字幕 — 但前厅角色没结束。后续访问解锁：

  • Throne Room 通路(经后期专属钥匙和谜题)。
  • Alternate Room 46 路线经 Atelier 和 Tunnel。
  • 圣殿本体 — 8 个 Mora Jai 拼图盒(见 Mora Jai 攻略)。

整个字幕后内容,前厅都是你的枢纽。

前厅 FAQ

能跳过前厅直接到 46 号房吗？ 不能。46 号房只有一扇门,就是前厅北门。
必须四扇门全开吗？ 不必。任一扇 S/E/W 门就够进前厅。北门是唯一通向 46 号房的门。其他门是替代入口。
Greenhouse 控杆真的坏？ 对。Greenhouse 内的注解承认这点。设计的诱饵。
津贴令牌可重复用吗？ 不可,但效果永久。一旦从石柱拿过,你的每日 Coin 上限永久上升。
