新手指南 — 抽取、宝石、钥匙与每日 Step

2026 年 5 月 25 日更新 · 11 分钟阅读 · 给新玩家的真实机制

Blue Prince 不会手把手教你。你只有一把钥匙、一个截止期、和一座每天重新排列的庄园。Roguelike 抽取系统让每局都不同,但有一小套底层机制统领全局。本指南覆盖头几局真正需要的内容 — 抽取系统、5×9 网格、四种稀有度、宝石成本,以及在追 46 号房之前该优先什么。

30 秒版本：庄园 5×9 = 45 间/日 + Rank 10 的 46 号房。每开一扇门,从 3 个选项里抽一间房。宝石成本(0/1/2/3/5)必须付,但每次抽取的第一个选项免费。资源每天重置,部分解锁跨 run 保留。目标:Rank 9 中心的前厅,然后通过它进 46 号房。

庄园网格

庄园是固定的 5 列宽 × 9 行高。起点是玄关(Rank 1,第 3 列 — 底部中心)。前厅固定在 Rank 9 中心。其他全部抽取。

  • Rank 1–3：多为普通房。难度低。
  • Rank 4–6：标准房。资源经济开始紧张。
  • Rank 7–9：少见和稀有房。会看到谜题房、圣殿层内容、实验室、温室。
  • Rank 10：只有 46 号房。

整个 Room Directory 有 110 间房。每天只能装下 45 间。实际能见到的池子,取决于你已在 Drafting Studio 解锁哪些房。

抽取怎么运作

每开一扇门,会看到 3 个房间选项。每个选项有：

  • 宝石成本：0、1、2、3、5 颗。
  • 颜色/类型标签：Red Room、Hallway、Shop、Green Room、Blueprint、Bedroom、Blackprint。有些房有两个标签。
  • 稀有度。

每次抽取的第一个选项免费。所以三个选项都要花宝石的情况下,你仍能免费抽一个。仔细选 — 另两个本次抽取消失。

四种稀有度

等级行为
Commonplace 普通低 Rank 极常见,高 Rank 减少
Standard 标准各 Rank 频率稳定
Unusual 少见低 Rank 罕见,Rank 5+ 增多
Rare 稀有Rank 1 几乎不出,Rank 7-9 常见

实际意义:Rank 1 别指望抽到实验室或天文台。统计上 Rank 5+ 才有概率见到。

四种每日资源

  • Step(步数) — 每日移动预算。默认上限 50(特殊模式如 Curse Mode 降到 13)。每日重置。
  • Coin / Gold(金币) — Shop、Pawn、特定谜题(书店的 A New Clue 卖 50 Gold 等)。部分跨日保留,部分重置。
  • Key(钥匙) — 开锁门。每日资源池。
  • Gem(宝石) — 付抽取成本。命脉资源。在矿坑、金库、客厅、各种谜题房赚取。

第 1 天该做什么

  1. 不要冲 46 号房。第 1 天是侦察。起始资源根本到不了 Rank 4 或 5 以上。
  2. 抽多出口房。早期避开死胡同 — 浪费抽取位。
  3. 读所有注解。注解、书、Blue Tents 小册子是谜题真正的说明书。金库、Boudoir 保险箱、Family Core 密文 — 全来自房间内注解。
  4. 钥匙留给箱子门。木门和普通锁用常规池开;箱门和金库保险箱需要特定钥匙。
  5. 带资源睡觉。带 10 Step 上床比 Rank 6 烧光好得多。

跨 run 保留的内容

多数每晚重置,少数永久保留：

  • Drafting Studio 解锁 — 加入抽取池的新房间蓝图。
  • 地下室门 — 用基础钥匙开过的门永远开着。
  • Vault Keys — 收集到的物品跨日保留。
  • Trophies — 在 Trophy Room 展示。
  • Found Floorplans — 找到的隐藏房蓝图永久保留。
  • 前厅石柱内容 — 每 run 重生,所以每次新尝试都能重领基础钥匙。

早期想抽到的房间

多数 run 值得优先：

  • Pantry / Coat Check — 跨日存物 + 退还 Step。经济神器。
  • Workshop — 合成铁铲、燃烧镜、探测铁铲等关键工具。
  • Library — A New Clue 密文、期末考、剧情都需要书。
  • Drafting Studio — 永久解锁新房蓝图。
  • Boiler Room 或 Electric Eel Aquarium — 通过通风口给相邻房(实验室等)供电。

升级碟(Upgrade Disks)

后期道具,永久给特定房间三选一加成。最佳目标：

  • 客厅升级 — 多一把风钥匙,猜错可补救。
  • 台球室升级 — 飞镖盘多一次尝试或提示。
  • 实验室升级 — 额外实验槽或持久触发器。

新手 FAQ

多久能到 46 号房？ 多数玩家 15-25 小时跨多个游戏日。速通老手知识下能单局达成,但要走 Day One Trophy 攻略。
该不该避开剧透？ 随你。46 号房作为发现是有满足感的,但 Blue Prince 谜题太多,可选的(Mora Jai、A New Clue、图画地图谜)开提示攻略合理。
Curse Mode 是什么？ 可选硬核模式。每日 13 Step,抽特定房产生 debuff。Curse Mode 下到达 46 号房得 Cursed Trophy。
有 DLC 吗？ 没有。设计师确认 Blue Prince 在 Patch 1.10 为终极版本,无 DLC、无内容更新,只有修复。
