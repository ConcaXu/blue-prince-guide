霍利山之冠 — 真结局核心道具完整攻略

2026 年 5 月 25 日更新 · 10 分钟阅读 · 全四神器路线

霍利山之冠是触发 Blue Prince 真结局的唯一道具。它不是被找到的——而是被锻造出来的。四件神器送入 46 号房间前厅深处的王冠之室，当全部就位时，房间会自动加冕、滚出最终过场。本文涵盖每件神器的位置、锻造路线（先后无所谓但路径有讲究），以及三种会毁掉一局王冠 run 的错误。

速查：四件神器——蓝宝石之眼（矿坑第 3 层）、铁圈（铁匠交易）、金鸢尾（温室 + 日循环）、星徽（天文台图案 A 夜）。在前厅内的王冠之室祭坛上合成，踏上祭坛即触发过场。

王冠为何重要

Blue Prince 共三个结局。前两个——标准结局（开 46 号房）与被遗忘之翼结局（客厅路线）——只需完成单个谜题、跨过单扇门。真结局完全不同：它必须收集触及每一个主要谜题系统的物品，所以王冠本质是一个元成就，表示"你已经接触过 Mt. Holly 的全部内容"。

实际建议：新存档第一天不要追王冠。先拿标准结局解锁前厅，再把王冠当成跨多局的长期目标规划。

四件神器一览

1. 蓝宝石之眼 — 矿坑第 3 层

三层矿坑最深的一层，由泵房 PSI 谜题门控。你需要：

  • 至少抽到一次泵房
  • L–R–M 拉杆顺序，PSI 刻度 40 / 60 / 80（详见泵房攻略）
  • 背包内有提灯——第 3 层黑暗，无提灯坠落直接耗光本局

掉到第 3 层后向南走。蓝宝石之眼在尽头的石质祭坛上。拿到后从第 2 层梯子爬回去——南侧没有返回路。

2. 铁圈 — 铁匠交易

铁匠小屋在外区，须先打通被遗忘之翼路线后才能进入（大多数存档第 7 天+）。你需要：

  • 3 个铁锭。每次成功通关宝瓶座管道掉 1 个，所以计划连续三局做这个谜题。
  • 15 个 Coin 锻造费。

把铁锭和硬币交给铁匠，铁圈当晚成形。它不占背包格——王冠类道具单独走神器栏。

3. 金鸢尾 — 温室双日开花

温室白鸢尾开花后解锁 +1 Gem/天。金鸢尾种子只在白鸢尾开花成功的下一游戏日才出现在种子抽屉里。种植顺序：

  1. 第 N 天：种白鸢尾，按左 → 右 → 中浇水，确认开花。
  2. 第 N+1 天：重抽温室，金鸢尾种子在抽屉右下槽位。
  3. 金种子只种中间花盆，开太阳灯（开关在种子架后）浇水。开花需要整整一天。
  4. 第 N+2 天：再抽温室一次，采摘金鸢尾。

这就是王冠是跨多局工程的原因——光温室就要三次抽取。

4. 星徽 — 天文台图案 A 夜

天文台日志有一列大多数玩家不会注意的边距。只在图案 A 夜（第 1、7、13 天——详见天文台攻略），盖章之后第三次按对焦旋钮，会在日志边距打印一个小星形图标。这就是星徽。把那一页从日志撕下，就是你的了。

错过第三次按，下一个图案 A 夜要再等 6 个游戏日。这是王冠 run 最常卡住的地方。

锻造王冠

王冠之室在前厅祭坛的北侧。进入条件：

  1. 四件神器全部在王冠栏里。
  2. 进入前厅（46 号房间必须已开过）。
  3. 走到北通道。手持四件神器时，墙壁滑开（少一件就是空墙）。
  4. 踏上里面的祭坛。王冠自动锻造完成。真结局过场立即触发。
顺序无所谓，但前厅每局重置。如果你在踏祭坛前先睡了，必须重新打开 46 号房才能回来。永远当天收齐当天合成。

三种毁掉王冠 run 的错误

  • 在当铺卖掉王冠神器。它们会出现在当铺的物品列表里，店主接受——卖掉后本存档永远找不回。
  • 无提灯下矿。没提灯掉到第 3 层会把蓝宝石之眼归零，矿坑下一天重置。
  • 收齐和合成之间睡觉。前厅重置——第 7 天+再开 46 号房就是又一局。
