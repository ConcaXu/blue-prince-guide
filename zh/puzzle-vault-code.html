金库 — Family Core 密文与 Vault Keys

2026 年 5 月 25 日更新 · 9 分钟阅读 · 基于 Wiki 真实机制

金库是一间死胡同房间,地上有 40 Gold,后墙是一排编号保险箱。谜题分两层:基于家族纹章罗马数字 MCCXIII 推导的 Family Core 密文(告诉你哪个保险箱最关键),以及全庄园分布的 Vault Keys(编号 149、233、304、370)用来开其他保险箱。本页覆盖两层,以及每把 Vault Key 的获取位置。

速查：MCCXIII 按 Blue Tents 注解拆四个数 → 1000 ÷ 200 × 11 − 2 = 53。各位数字相加 5+3 = 8 → Key 8 开 53 号保险箱。另四把 Vault Keys(149、233、304、370)来自挖掘点、Throne Room、Bunk Room、Locker Room、Music Room 等。

MCCXIII 来自哪

家族纹章上刻着 MCCXIII。同一纹章在两间早期房见到：

  • 酒窖。挂在酒架上方。同房间一张 Blue Tents 注解说罗马数字编码四个不同数。
  • 主卧。挂在壁炉上方。

机械馆的第二张 Blue Tents 注解明确拆法:第一个罗马数字是单一数,后面三个数各由相邻两个罗马数字组成。

把 Family Core 化简为一个数

MCCXIII 拆为 M · CC · XI · II,得四个数 1000、200、11、2。按注解的乘除减序列收敛：

1000 ÷ 200 × 11 − 2 = 53

金库内一张 Blue Tents 注解:"Family Core 只能由其各位数字之和解锁。"所以：

5 + 3 = 8

Family Core 保险箱编号 53,开它的钥匙是 Key 8 — 来自另一条谜题链(见图画地图谜页给出 Key 8 的箱子)。

四把编号 Vault Keys

除了 Family Core 箱,金库还有更多编号保险箱,由四把 Vault Keys 开。每把都有多个可能来源 — 一般每天只能见到一两把。

Vault Key可能来源
149Throne Room、Bunk Room、Locker Room(储物柜)、Music Room(持 5 大钥匙中的 3 把)、挖掘点
233Throne Room、Locker Room(储物柜)、Music Room(条件下)、挖掘点
304Bunk Room、Music Room(条件下)、挖掘点
370Throne Room、Music Room(条件下)、挖掘点
从 Cloister of Mila 抽到的 Bunk Room：如果是从 Cloister of Mila 内部抽到 Bunk Room(不是常规池),四把 Vault Keys 可能全在那里出现。一局清空金库的最快路径。

挖掘点 — 备用来源

Vault Keys 也在挖掘点掉落。需要：

  • 工坊里的铁铲,或探测铁铲(铁铲 + 金属探测器合成)。
  • 可见的挖掘点标记(小土堆,通常在外区路径附近)。

探测铁铲每天能露出更多挖掘点,凑齐部件后强烈推荐。

金库内部

金库是抽取池里少数的"死胡同"房 — 只有一扇门,进出共用。里面有：

  • 40 Gold 散落地上,每次进入都能免费拿。
  • 后墙编号保险箱。编号与你已收集的 Vault Keys 对应,加上 53 号 Family Core 箱。
  • Blue Tents 注解在侧桌 — 确认"各位数字之和"规则。

保险箱里东西各异 — 多数混合宝石、金币、一次性道具。Family Core 箱(53)是剧情核心:含一份与 Throne Room / Crown of Fenn Aries 路线相关的文件(见全结局)。

金库 FAQ

金库密码是 4558 吗？ 不是。早期攻略传开的粉丝迷思。真实金库没有单一 4 位转盘密码 — 它是编号保险箱,各由特定 Vault Key 开。Family Core 谜题(MCCXIII → 53 → Key 8)是大多数玩家口中的"金库密码"。
结局必须收齐所有 Vault Keys 吗？ 不必。特定钥匙对应特定箱奖励。Family Core 箱(53)对 Throne Room 结局最相关,其他是宝石/金币掉落。
Family Core 数学每存档不变吗？ 对。MCCXIII 在每个存档都化简到 53。密文固定。
Boudoir(闺房)的保险箱呢？ 另一个谜题。闺房有独立保险箱,4 位日期密码(1225 — 12 月 25 日圣诞场景)。详见图画地图谜页的 8 个日期保险箱表。
