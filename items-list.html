Blue Prince Items & Keepsakes

Updated May 14, 2026 · 10 min read · Reference

Every item in Blue Prince, sorted by how long it lasts. Three buckets: day-bound consumables, persistent items, and permanent keepsakes. Knowing which is which lets you plan multi-day strategies confidently.

Day-Bound Consumables

Lost when the day ends. Use them or lose them.

ItemSourceEffect
StepsPantry, Kitchen, ConservatoryCurrency for crossing doorways. Resets to 50 daily.
GemsMine, Storeroom, gem chestsPay for room placement. Reset daily unless stored.
KeysLocksmith, drawers, VaultOpen steel doors. Reset daily.
CoinsSofas, jars, the Wishing WellSlot machine, vending devices. Reset daily.
Lens FragmentLibrary or Reading RoomCrafting component for Telescope Lens.
Optical FrameLabCrafting component for Telescope Lens.

Persistent Items (Survive Day End)

Permanent Keepsakes

Saved to the file forever. These are what create progression in Blue Prince — a roguelike where the player's knowledge + a small set of permanent items defines the meta-progression.

ItemSourceEffect
Master KeyAntechamberOpens 1 steel door per day for free.
Marksman's PinFirst Vault open + Trophy RoomSkip 1 Vault code attempt per run.
Crown of Mt. HollyCellar (Mine layer 4)Triggers True Ending when carried into Room 46.
Boiler BonusBoiler Room solve+1 Gem yield in Mine forever.
Architect's NotebookRead all 3 Forgotten Wing fragmentsReveals room cards' rarity colors during draft.

Crafting Combinations

Crafting happens at the Workshop or Lab. Recipes:

RecipeInputsStationOutput
Telescope LensLens Fragment + Optical FrameWorkshopTelescope Lens
Reinforced CuePool Cue + 3 GemsWorkshop+10% Dartboard accuracy
Polished Brass KeyBrass Key + Lab catalystLabBrass Key with extra durability (cosmetic only)
Don't lab the Brass Key without confirmation. The "Polished" version is cosmetic but the Lab consumes the original — and you only get one Brass Key per descent. If a run depends on Room 46, skip the Lab.

Where to Find Each Item — Quick Reference

  • Vault Code letters: Den, Library, Office. See Vault code derivation.
  • Brass Key: Mine layer 3 only. 6 Gems total descent.
  • Telescope Lens components: Lens Fragment (Library/Reading Room), Optical Frame (Lab).
  • Master Key: Antechamber chest. First-ever entry only.
  • Marksman's Pin: Vault interior on first-ever open, OR Trophy Room reward after Dartboard solve.
  • Crown of Mt. Holly: Mine layer 4 (Cellar). Brass Key + 12+ Gems on hand.
  • Architect's Notebook: Read 3 Forgotten Wing journal pages in chronological order.

Items FAQ

How does inventory work? Three buckets: day-bound (lost at day end), persistent (survive day end), permanent (saved forever).
What does the Brass Key do? Opens Room 46. Found only at Mine layer 3.
Most important item? Brass Key first, then Master Key, then Crown.
How to craft the Telescope Lens? Workshop: Lens Fragment + Optical Frame.
Are items random? No. Each item has a fixed source. The room they spawn in is randomized per run, but the item list is deterministic.
