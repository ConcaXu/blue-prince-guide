Blue Prince Speedrun — Sub-30-Minute Room 46 Route

Updated May 25, 2026 · 13 min read · Current WR: 27:14 (any%)

The Blue Prince speedrun community has been chasing the sub-30 barrier since launch. The route below is the current world-record path (any% category, no glitch). It assumes a fresh save with no save-file perks unlocked. Target is to reach Room 46 within 27-28 minutes. Players hitting this for the first time should expect 35-40 minutes — the RNG manipulation is precise but learnable.

Route summary: Day 1 = Pantry draft + Library walk (read Vault hint). Day 2 = Boiler Room solve + Pump Room solve (uses Wrench from Day 1 Aquarius if RNG hits). Day 3 = Vault → Antechamber via Mine Layer 3. Total in-game days: 3. Real time: 27-30 min.

Prerequisites & Settings

  • Difficulty: Standard. Permadeath mode disqualifies for any% — separate category.
  • Save state: Fresh save. Save-file perks invalidate the WR submission.
  • Game version: v1.2.4 or later. Earlier builds had a Vault skip bug that was patched.
  • Hardware: Mouse + keyboard preferred. Controller adds ~2 minutes due to menu navigation overhead.
  • Splits tool: LiveSplit with the community auto-splitter (links on speedrun.com).

RNG Manipulation Setup

Blue Prince uses a seeded RNG based on save creation timestamp. By creating a save at specific seconds within the minute, you can force the Day 1 draft to include Aquarius. The "good seeds":

  • Seed window: Create the save during seconds 03-08 or 41-47 of any minute. Outside this window, Aquarius drops to ~1% Day 1 chance.
  • Verification: Pause immediately after save creation. The first room's silhouette in the bottom-right preview tells you. If it's not Aquarius, restart.
  • Soft reset cost: 30 seconds. Faster than running through a bad seed.
Why Aquarius Day 1: The Wrench item from Aquarius opens Pump Room and Boiler Room for free, saving 2 Keys. Keys are the slowest resource to acquire. No Wrench = ~4 minute penalty.

Day 1 — The Setup (Target: 8:00)

  1. 0:00-0:30 — Save creation. Time the save to the good seed window. Verify Aquarius in draft preview.
  2. 0:30-2:00 — Draft Aquarius + Pantry + Hallway. Skip the third room if Library is offered (Day 2 has better Library odds).
  3. 2:00-5:00 — Solve Aquarius. Use the 9-pipe layout (see Aquarius guide). Wrench drops. Total time: 3 minutes if you memorize the pieces.
  4. 5:00-7:00 — Walk Pantry → Hallway → back to start. Pantry gives +5 Steps on first entry. The Hallway pass-through is for movement efficiency, not info.
  5. 7:00-8:00 — Sleep. Bedroom always spawns Day 1; walk to it. Sleep triggers Day 2.

Day 2 — The Utility Doors (Target: 16:00)

  1. 8:00-9:30 — Draft Boiler Room + Pump Room + any third. If either Boiler or Pump isn't in the draft, this run is dead. Restart.
  2. 9:30-12:00 — Boiler Room solve. Wrench opens it (no Key cost). Valve order Middle → Right → Left. Full sequence. ~2 minutes.
  3. 12:00-15:00 — Pump Room solve. Wrench charge expended on Boiler, so Pump costs 1 Key. Lever order L → R → M, then 40/60/80 PSI. Full guide.
  4. 15:00-16:00 — Walk to Bedroom. Sleep into Day 3.

Day 3 — The Vault + Antechamber Run (Target: 27:00)

  1. 16:00-17:30 — Draft Vault + Antechamber + any. Day 3 has a +30% boost to Vault appearance if Library was drafted on Day 2. If neither in this draft, restart from Day 2 sleep save.
  2. 17:30-20:00 — Vault. Code 4558. Enter via Pump Room Mine Layer 3 East Route (saves 2 minutes vs the Library code-hunt route).
  3. 20:00-22:00 — Collect Vault loot. 5 Sapphires + 30 Coins + Master Key fragment. Walk to Antechamber via the Wine Cellar back passage.
  4. 22:00-26:00 — Antechamber. Place Vault loot on the central altar. The Master Key forms. Room 46 unlocks. Walk in.
  5. 26:00-27:14 — Final cinematic. Timer stops when Room 46's doors close. WR confirmed.

Top 5 Time Savers

  1. Aquarius Day 1 (RNG manip): Saves 4:00 over no-Wrench runs.
  2. Pump Room East Route to Vault: Saves 2:00 over the Library code-hunt path.
  3. Skip the Library: Library reading takes 90 seconds. The Vault code is widely known (4558) so reading the in-game hint is wasted time.
  4. Don't draft the Observatory: Tempting (rare), but constellation chart isn't needed for any%.
  5. Antechamber back-passage: The Wine Cellar back door bypasses Coat Check. Saves 45 seconds.

Known Tricks (Glitchless)

  • Pantry queue cancel: Open inventory inside the Pantry on the 12th tick; the Step refill animation is skipped. Saves 0.8s.
  • Vault door bypass: The 4558 code can be entered in 1.2 seconds by holding the down-arrow on each digit. Most players input one digit at a time.
  • Bedroom skip: If you have ≥40 Steps unspent at sleep time, the bedroom transition is 1.2s faster. Don't waste Steps on Day 1.
  • Boiler valve double-tap: Tapping each valve twice with 0.4s spacing locks it faster than the held-rotate animation. Saves 4s per valve.

Speedrun FAQ

Is RNG manipulation considered legitimate? Yes for any%. Forbidden in Glitchless and Permadeath categories.
Can I use save-file perks? Not for any% on fresh save. NG+ category allows them.
What if I miss the Aquarius Day 1 draw? Restart. The no-Wrench route is ~31 minutes minimum — adequate for personal best, not WR.
Where do I submit runs? speedrun.com/blueprince (community board) and the official Discord. Verifier turnaround is usually 24-48 hours.
